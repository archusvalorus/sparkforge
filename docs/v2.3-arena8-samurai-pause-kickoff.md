## Contract and source approach

- Retain the original 0.40-second SpriteKit windup and visual frame durations. Pause only the pending Samurai node/subtree during holds; SpriteKit retains elapsed/remaining time. Snapshot and restore that node's previous own pause flag, without modifying child flags or the world's/Scene's pause policy.
- Manual pause, level-up, Remove Ads modal, synergy reveal, Terra placement and boss reveal hold the pending strike. Background is a separate Samurai hold, including background entered while another modal was already open. Clearing one hold does not clear another.
- A token identifies each pending strike. A completion that becomes ready during a hold stays pending; it is not spent, redirected or duplicated. When released, deliver a ready completion through the action phase rather than synchronously inside a modal setter. Recheck the token and hold before delivery; clear pending state before calling Scene combat code.
- Death/revive, reset, Title/Scene detachment, node removal and explicit action cleanup invalidate the token and cancel only pending strike work. Revive cannot rearm a canceled strike. Key strike clock/ready/fallback sword work separately so canceling it does not erase unrelated Panda actions.
- Scene snapshots visitor nodes and rereads current hold/terminal state for each. Damage can synchronously change state or remove visitors; reacquire node identity after damage rather than writing through a stale index.
- Keep the original mark, existing validation and damage/execute/reward code. No reacquisition, bonus hit, catch-up batch, new duration or card exclusion.

The old G20 root harness explicitly stubs this new lifecycle dependency and remains root/targeting evidence only. Its runtime observation of the inherited pause defect must now expect a pending unspent strike, not an impact while paused. Historical frozen G20 evidence is preserved unchanged.
