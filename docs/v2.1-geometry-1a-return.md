## Final data structures + insertion seams

Exactly the reconciliation §4 shape:

```
ArenaGeometry { blockedFootprints, routeNodes, routeEdges, spawnZones, safeAnchors }
Footprint { center, halfExtents, cornerRadius, rotation, label }
  contains(p, margin) · resolve(p, actorRadius) · intersectsSegment(a, b, travelRadius)
PlacementSampler.randomPoint(in:, minRadius:, maxRadius:, margin:)   // area-uniform, rejects, never nil
```

- **Enforcement = displacement**, monument precedent, no physics body.
  Physics bit «3 (`boundary`) left as-is (reconciliation: not work for its
  own sake).
- **`resolve` iterates** (≤4 gradient steps): a rounded-box SDF is exact
  outside but a lower bound inside, so a one-step push undershoots from
  deep interior. Found by the proof harness, fixed, re-proven idempotent.
- **`geometry` is a builder on ArenaConfig, materialized once per
  `setupArena`** — layouts size off the live arena radius, and a stored
  geometry inside a `static let` config recursed into its own
  `dispatch_once` (SIGTRAP at first launch; same class of bug as the
  frozen `spawnDistance`, fixed the same way).
- **Seams (all announced by the HUD banner while on):**
  `GeometryDebug.showOverlay` (draw footprint/margin/routes/gates/anchors)
  and `GeometryDebug.forceSplitworksShell` (play any selected arena AS the
  shell, via the transient Boss-Mode override — cleared on return to
  title, never persisted; the shell is not in `ArenaConfig.all`, so
  progression can't see it). Both `false` at HEAD; sim reinstalled cold.
- **Actor footprint radius** is explicit and separate from contact bodies
  (§7.2). Reads scale, unlike the physics body.

## Performance sample

- **Synthetic (host):** Apple M5 Pro, `swiftc -O`: 300 enemies resolved +
  3 player resolves + 20 swept segment tests per frame = **0.003 ms/frame**
  (0.02% of a 16.67 ms budget). Even at 50× slower silicon this is <1% of
  a frame — the bounding-circle pre-reject does its job.
- **Simulator (iPhone 17 Pro sim, iOS 26, debug build):** Splitworks shell
  with overlay on, early run: 60.0 fps, 125–131 nodes. Not a swarm; the
  sim can't show headroom above 60.
- **Device floor: NOT MEASURED.** Per the reconciliation, no invented

# Unit 1B return — authored route graph + recovery (appended)

*Built on the 1A pass verdict, same session. Scope per reconciliation §5
Unit 1B; proof against its criteria.*

**Shape:** one steer pass (`routeSteerTarget`) ahead of the chase dispatch —
the §4 decision-point model verbatim: direct-clear → pursue directly
(open arenas always short-circuit); blocked → commit to a visible node
scoring `d(enemy,node) + d(node,goal)` with a backtrack penalty
(oscillation guard) and a 0.4s re-decide cooldown (thrash guard); commit
holds until arrival (28pt), invalidation (displacement broke the line),
or the direct line clearing. No node visible → beeline+slide, counted.
All ten chase behaviors untouched — they chase whatever point the steer
hands them; multi-hop routes emerge from arrival→re-score (no path
search). Tunables in `GameConfig.Routing`. Ranged mobs inherit routing;
their LoS-aware FIRING stays Unit 2 scope (Ruling 4).

**Proof (Splitworks shell, live run, overlay + counters):**
- Enemies from the far side reach the player around either flank —
  level-10 run at 1:25 with continuous kills + contact damage taken.
- Counters after ~90s: **decide=84 · recover=0 · fallback=0 · resume=38**
  — zero frames with no visible node (the 6-node graph covers the yard),
  zero displacement recoveries needed, clean direct-pursuit resumes.
  No oscillation observed (backtrack penalty + cooldown).
- 60.0 fps at 314 nodes with overlay + 5Hz commitment-line drawing on.
- Diagnostics: per-enemy commitment lines (5Hz, DEBUG+overlay only) +
  a 10s `[GEO]` counter dump; the 1A "events not drawn" gap is closed
  for routes (drawn) — rejected-sample markers remain counter-only.
- Deterministic + tunable: three constants, greedy scoring, no black box.

**Also in-unit:** AudioManager engine-start backoff (a wedged CoreAudio
daemon in the sim aborted inside `AVAudioEngine.start` — one retry per 5s
now; device risk was already negligible, retry-storms now impossible).

**Recommendation:** Unit 2 can proceed — the roster's spatial verbs
(Spurhound flank = this steering + emergence tells; Linekeeper anchor =
segment tests; Ramplate = charge + wall-termination precedent) all have
their primitives proven. Projectile blocking + targeting LoS are Unit 2's
