## SHIP BLOCKERS

1. **`MARKETING_VERSION` is still 1.9.** Bump to 2.0.
2. **Three premium-skin IAPs don't exist in App Store Connect.** Product IDs are
   hardcoded and must match EXACTLY:
   - `com.brandon.Sparkforge.skin.primeember`
   - `com.brandon.Sparkforge.skin.starcrossedprime`
   - `com.brandon.Sparkforge.skin.flamepanda`
   Non-Consumable. There's also no `.storekit` config in the project, so
   purchases can't be tested locally. Restore Purchases already exists (Apple
   requires it — verified).
   Naming convention agreed: Display Name `Spark - <Skin Name>`; reference name
   `Skin — <Family> — <Name>`; **do NOT mark any as a Promoted IAP** (that
   surfaces Flame Panda on the store page and leaks the secret tree).
   Pricing per skin canon: $4.99 baseline, $9.99 for Flame Panda.
3. **NOTHING has been tested on a real device.** All simulator. That's the
   studio's own final gate, and this is the worst release to skip it on: 44 new
   textures and Growth scenes hitting 600+ nodes on an M-series Mac that a
   3-year-old iPhone may not match.

## New operating discipline (reusable, not v2.0-specific)

- **`docs/character-art-playbook.md`** — the mold. Size before commissioning,
  points not pixels, body-raster/effects-procedural, animate by screen time,
  union-box cropping for frame sets, and the warning that animated sprites do
  not render at the size the arithmetic predicts.
- **`docs/art-briefs.md`** — what was asked for and the creative intent.
- **`art/source/<character>/`** — drop folders with a README carrying the
  convention. Sources committed so assets can be re-cut without Lyra.

**Skin tier rule (new canon):** earned skins RE-TINT; premium skins add FORM and
FIRE. A recolour can't justify a price when the free tier already recolours.

**Sprite vs procedural rule (new canon):** does it need to keep being Spark?
Yes → palette or overlay (keeps eye tracking, breathing, damage flash, and
composes with other overlays). No → sprite.
