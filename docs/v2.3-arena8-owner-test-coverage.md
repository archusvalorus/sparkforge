# Arena 8 owner-test coverage boundary

This is the opt-in, memory-profile six-room test using provisional existing basic/ranged enemies. It is not a production Arena 8 registration, final roster/boss build, App Store candidate or catalog-wide compatibility certification. Normal drafting, offers and exclusions are unchanged; this table does not ban or hide cards.

## Mechanics exercised through the Title route

G17–G20 evidence enters the actual `TitleScene.startGame` → `transitionToGame` → `GameScene.didMove` path. Each retained technical report is paired with an entry receipt proving Title origin, selected two/six-room map, actual wall geometry, safe player start and memory isolation. Separate native input uses the real Play button twice with Menu → Title between runs; autoplay is not substituted for native evidence.

## Compatibility closures and remaining work

- **Ice Rink:** G18 closes the six-room ground-fill mismatch using the true walkable union. Legacy circle/two-room/Release art remains original. Decorative stroke/glow around the boundary is not a new damage or movement area; whole-catalog/performance certification is not inferred.
- **Void Horror fear:** G19 adapts six-room goals and steps to authored bounds and full-body solid geometry. It preserves the existing away heading/deviation order, speed/slow and fear eligibility/clocks; certified actual Float endpoints survive the final resolver only when later forces leave them unchanged. Legacy circle/two-room/Release remain original. This is directional movement evidence, not every mixed-build or performance certification. Invalid starting roots hold; no new teleport recovery policy was added.
- **Panda special cases:** G18 closes stationary stacked-child and after-kaiju-witness birth roots using the existing Float-safe 20-point rule, and guards delayed avalanche visual start against retired/detached/replaced visitors. Active avalanche offsets, delay, movement and combat remain original; G14's safe terminal rest still applies. This is not full avalanche combat certification. G20 closes the named Samurai stationary handoffs, preserving live tracking, travel, delayed strike, target validation and timers. It does not recover every corrupted in-flight approach, certify complete sprite-art containment or close complete kaiju/body and avalanche combat coverage. G16's health-drop birth rule remains 12 points.
- **Samurai manual pause:** actual phone/iPad checks reproduced the inherited delayed strike completing during the manual pause menu while phase timers stop. The shared pause/strike code is unchanged by G20. This is a separate lifecycle issue and decision gate, not a passing claim of complete pause semantics.
- **Universal wall policy:** remains undecided. Do not normalize existing intentional projectile/spectacle exemptions as part of a routing fix.
- **Rainbow:** live drafting/production integration remains OFF and separate from the accepted sweep prototype/policy proof.

These gaps are not silently removed from the normal card pool. Owner test findings involving them must be classified against this boundary; unrestricted card compatibility is not claimed. Completing the remaining mechanical adapters precedes a claim of production readiness. Final authored new enemies/boss, arena registry/unlocks, save/reward/victory wiring and release work are separate later gates; they need not prevent a bounded existing-enemy owner test of the current floor and supported mechanics.
