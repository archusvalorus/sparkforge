# Arena 8 owner-test coverage boundary

This is the opt-in, memory-profile six-room test using provisional existing basic/ranged enemies. It is not a production Arena 8 registration, final roster/boss build, App Store candidate or catalog-wide compatibility certification. Normal drafting, offers and exclusions are unchanged; this table does not ban or hide cards.

## Mechanics exercised through the Title route

G17/G18 evidence enters the actual `TitleScene.startGame` → `transitionToGame` → `GameScene.didMove` path. Each retained technical report is paired with an entry receipt proving Title origin, selected two/six-room map, actual wall geometry, safe player start and memory isolation. Separate native input uses the real Play button twice with Menu → Title between runs; autoplay is not substituted for native evidence.

| Area | Retained checks rerun through Title | Boundary |
| --- | --- | --- |
| Movement, basic/ranged combat, shots/Long Shot, XP/upgrades, death/reset and pause | `--arena8-six-checks`, two-room `--arena8-game-checks` | Provisional shipped encounter rules; no new roster/boss/victory/unlock contract. |

The controls use deliberate fixtures or controlled selections to reach these behaviors. This proves their room adapters remain reachable after Title initialization. It does not prove natural random draft probability, every card combination, every capstone or device performance. Existing catalog/UpgradeManager and other regression harnesses remain separate evidence.

## Compatibility closures and remaining work

- **Ice Rink:** G18 closes the six-room ground-fill mismatch using the true walkable union. Legacy circle/two-room/Release art remains original. Decorative stroke/glow around the boundary is not a new damage or movement area; whole-catalog/performance certification is not inferred.
- **Void Horror fear:** `GameScene.fleeGoal` still supplies the old circle radius; `VoidState.FleeRule.goal` and `fleeStep` return nil/hold when a body is outside that radius. Legal outer-room bodies can therefore need a rectangular-room fear adapter. This is a source-verified compatibility gap, not covered by safe well-birth tests. The intended away-from-Spark/solid-wall constraints must be preserved in its own bounded qualification.
- **Panda special cases:** G18 closes stationary stacked-child and after-kaiju-witness birth roots using the existing Float-safe 20-point rule, and guards delayed avalanche visual start against retired/detached/replaced visitors. Active avalanche offsets, delay, movement and combat remain original; G14's safe terminal rest still applies. This is not full avalanche combat certification. Samurai tracking/strike roots and complete kaiju/body interactions retain their separate scope limits. G16's health-drop birth rule remains 12 points.
- **Universal wall policy:** remains undecided. Do not normalize existing intentional projectile/spectacle exemptions as part of a routing fix.
- **Rainbow:** live drafting/production integration remains OFF and separate from the accepted sweep prototype/policy proof.

These gaps are not silently removed from the normal card pool. Owner test findings involving them must be classified against this boundary; unrestricted card compatibility is not claimed. Completing the remaining mechanical adapters precedes a claim of production readiness. Final authored new enemies/boss, arena registry/unlocks, save/reward/victory wiring and release work are separate later gates; they need not prevent a bounded existing-enemy owner test of the current floor and supported mechanics.

G18 entry/root/art evidence and exact limitations are recorded in [its return packet](v2.3-arena8-room-cleanup-return.md). Void Horror remains planning-only in [the directional test plan](v2.3-arena8-void-fear-test-plan.md); no fear repair or card exclusions were folded into G18.
