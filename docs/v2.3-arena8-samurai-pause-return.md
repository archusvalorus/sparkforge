# G22 — Samurai windup pause correction

Base: G21 `fa7d59bc47e1cd142448f7daf5c9c4af93ff1c4e`. Isolated candidate only; separate reviewed ACP is required. Arena 8 production activation remains off.

## Behavior

Pending Samurai windup and its artwork freeze during manual pause, level-up, Remove Ads, synergy reveal, placement and boss reveal. Background is an independent hold, so dismissing a modal while backgrounded cannot release the strike. Resume retains the original remaining portion of the 0.40-second windup and delivers once. A ready callback is token guarded and deferred to an action phase, never delivered synchronously from a UI/state setter. Death/revive, reset, Title/Scene detachment, removal and explicit action cleanup cancel it. Existing target validation, damage/execute/rewards, visual durations, other Panda acts and wall behavior remain unchanged.

This owner-approved pause correction intentionally applies to ordinary arenas and Release, not just the six-room Debug preview. It does not change the global Scene/world pause policy or certify every other action clock. The Scene iterates snapshot nodes and reacquires identity after damage, avoiding stale array indices when combat opens a hold or removes a visitor. Existing own-node pause ownership is restored rather than cleared indiscriminately.
