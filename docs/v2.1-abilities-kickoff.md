## Decided — do not relitigate

- All 28 numbered calls (Q-F/C/S/B/G/V) as recorded in the spec's DECIDED
  blocks. Canon amended: T4 allowed, one designated capstone per tree.
- Signatures are HARD gateways (provides/requires + pity), not soft
  weights. Red Smile requires both Bleed and Void signatures.
- Growth untouched. **Neutral rework POSTPONED to v2.2+ (Brandon, Sep 15)** — v2.1 ships Neutral unchanged; it slots into a later systems-heavy version.
- Tier percentages are totals; attack-speed % = firing-rate increase.
- **Dependency labels** (closure pass 1): **ARCH** rows block a unit's
  architecture (CL-1, CL-3, CL-5 — all now closed); **PARAM** rows are
  numbers that need an approved initial setting before the mechanic is
  TESTED — build the mechanic, but never ship an unapproved recommendation
  as the default value.
- **Prerequisites ship with each tree.** Every unit authors its own cards'
  `provides`/`requires` as it lands (signature gates, Glacial Spikes, Ice
  Rink, Red Smile's dual gate). A7 is the comprehensive eligibility and
  migration AUDIT, not the first point where prerequisites work.
- **Placeholder tells ship with the mechanic.** Every new mechanic lands
  with a readable procedural tell (ground mark, ring, flash, silhouette
  change); art polish follows in A9.
- **Release shape (Brandon, Sep 15 — overrides any split proposal):** ONE
  release. v2.1 = Arena 6 The Splitworks + the ability rework (A0–A7) +
  the signature draw already on main + rewards/content, tested together.
  The date moves back a week or two rather than splitting: one clean
  close on the new mechanics and the new arena, and v2.2 gets faster for
  it. Neutral redesign stays unscheduled backlog.
- **Signature-draw compatibility (verified Sep 15):** the shipped draw
  works against the CURRENT pool independently of the rework — seven
  signatures each `provide` a capability, only Growth's cards `require`
  one, so no gateway depends on a capability that arrives later. Harness
  22/22. Interim signatures (Repulse for Guard, Needlepoint for Bleed)
  are replaced by the rework's entry cards IN THE SAME RELEASE, so the
  swap is never live-visible.
