## Contract

- Six-room preview only: each kaiju action increment uses the existing straight swept-displacement contract, followed by Float-stored endpoint and whole-segment validation. Failed resolution holds the current root. It never projects across a wall or restores a stale launch anchor.
- Requests are incremental from the current root, using the current effective collision radius. Each segment consumes elapsed displacement even when blocked; no collision debt is carried into later callbacks.
- Keep recoil -0.25R / 0.08 seconds, forward +0.55R / 0.07 seconds and settle -0.30R / 0.14 seconds. Keep the `kaijuLunge` replacement key. Each new segment owns its own elapsed-state capture.
- Preserve melee/aura damage, reach, impact calculation, target choice, victim shove, kill credit, XP, animation, facing and claw art. The enlarged artwork does not enlarge Spark's collision body.
- Ordinary axis-sliding movement stays separate. Circle arenas, the two-room control and Release retain the original move-action sequence.
- Do not change pause, expiry, death or cleanup policy. Existing expiry/death leave a residual lunge; reset removes actions. This unit constrains residual movement where the six-room adapter is installed, without adding a new cancellation guard.
