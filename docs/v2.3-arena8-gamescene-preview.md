# Arena 8 G1 internal preview

No owner intermediate playtest is required for this unit; delegated checks are retained in the return packet. For an optional preview, use the shared Sparkforge scheme, Run configuration **Debug**, and enable only `--arena8-game` under Arguments Passed On Launch. Stop/relaunch to change arguments. Ordinary Run without an enabled lab argument opens the normal title. Release ignores this lab.

This opens actual GameScene combat on the accepted two-room greybox, not the eventual six-room Arena8. Use the existing dynamic joystick, normal automatic shots, real XP/stat/card menus and the normal pause button. Existing chaser/ranged fixtures use validated room positions; there is no boss. Player-follow camera retains normal scale. The cyan bottom badge identifies the room lab and memory profile.

The clean memory profile has ordinary fresh-profile availability; no cards were removed from the draw pool. For bounded testing, choose ordinary lower tiers (e.g. Swift, Magnetic Core, shot/range upgrades); Erasure Echo edge origins, Terra/radius caps and unrestricted high-tier spatial combinations are not accepted rectangular contracts yet. This is not a promise that every spatial card is integrated.

Pause → Menu returns to the normal title inside the same isolated process. Play there creates a circle scene; relaunch with `--arena8-game` to return to the rooms. To leave isolation entirely, remove the argument and relaunch. No profile data is saved by the isolated session, including Codex; ads/purchases do not execute or grant rewards.

Technical replay only: add `--arena8-game-checks` together with `--arena8-game` on an isolated Simulator. It runs actual-scene checks, writes Documents/arena8-game-checks.json and ends at title. It is a destructive-to-the-test-run check seam, not a player mode. No launch/scheme settings were changed on the owner's behalf.
