## Implemented

A run-owned pure Swift ledger stores explicit stable actor UUIDs, one owning carrier and supplied escort identities. Registration rejects duplicate membership atomically. Commands capture generation, packet revision, command identity/source and connection ID; prepare, active-time warning and explicit commit are separate. The caller must validate actual reachable/body-clear destination and current living set again at commitment. Holds freeze warning time and prohibit commitment. The ledger never moves or targets an actor and cannot itself cancel attacks.

Membership removal requires a captured run-generation/packet-incarnation/member ticket. Owner loss releases surviving escorts exactly once without deleting/rewarding actors. Escort loss invalidates an uncommitted warning; committed navigation snapshots expose only current surviving members. Reset rotates the epoch and removes all associations. No arbitration between carrier and signaler is implemented; only the owning carrier is an accepted source.
