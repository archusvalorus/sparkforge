## The rule, as implemented (locked answers ✓)

1. **Level-1 spread = random 3 of the active signatures** — while the run
   holds zero signature cards, `drawCards` offers only signatures.
2. **Reroll allowed, prioritizes unseen** — the draw remembers which
   signatures this level has shown; a reroll seats the unseen ones first
   (5 active ⇒ 2 unseen + 1 returning). It can never escape the rule.
3. **Second tree = gateway pity** — every signature `provides`, so all of
   them inherit the pity floor exactly as Terra always has. No forced
   second offer.
4. **Neutral excluded from the first spread** — it has no signature, so
   the opening branch excludes it structurally; it flows again from the
   very next spread.
5. **Boss Mode obeys** — the DRAFT opener's round 1 goes through
   `triggerLevelUp()` → `drawCards` and becomes a real signature pick.
   The RANDOM (chaos) opener's first grant is also a signature — the run
   is handed an identity, not a dead-end amplifier. (`+1 Card` during the
   opening draws an unseen signature too — it widens the identity choice.)

Panda untouched: an eligible run's panda keeps its mid-spread seat even
during the opening (validated), and the secret scheduler still stands
down for granted draws.

## Two real engine findings, found + fixed in-unit (proof harness)

Both are latent multi-gateway bugs that were invisible while Terra was the
only gateway, and would have shipped silently with eight:

1. **Pity claim-order starvation.** Several gateways maturing on the same
   level each overwrote `drawn[0]` and reset their counters — only the
   last in card order was ever shown; with the one-claimant fix iteration
   order then favored early-pool gateways forever. Now ONE claimant per
   draw, the longest-waited, so a matured set cascades in one per level.
2. **Displaced-offer reset.** A gateway that landed in the spread
   naturally was counted as "offered" even when the pity claimant (or
   another seating rule) then displaced it — pushing its next guaranteed
   offer a full cycle out. Counters now reset from the FINAL spread, at
   the bottom of `drawCards`: only what the player actually sees counts.
