# Arena 8 mixed-pressure comparison

Brandon approved the controlled baseline versus 25% more spawn attempts comparison (20% shorter intervals), with existing carrier/Signaler roles alongside basic/ranged waves. This is provisional test tuning, not final balance. Base: published Signaler commit `d9e4c3102a030814113c35b335b631019295e107`. Implementation remains isolated until qualification, independent review and separate ACP.

## Entry and controls

Use Sparkforge / Debug with `--arena8-six --arena8-title --arena8-mixed-pressure`. Add `--arena8-pressure-trial` for the faster profile; omit it for baseline. These are separate fresh process/run comparisons, not an in-combat rate switch. Normal Run without lab flags is unchanged. The older carrier/Signaler-only flags and legacy traversal/late-start/gun-off pressure flags conflict with this mode; mixed mode then stays disabled with a visible conflict badge. Do not combine labs.

Title → Play makes the same single ordinary startup attempt in both profiles. Ordinary basic/ranged waves then run continuously. SPAWN PACKET manually adds the existing one carrier/Spurhound/Linekeeper group; SPAWN SIGNALER adds at most one source. MIGRATE/SIGNAL retain the existing same-room, first-valid-order and one-active-second warning rules. Commands never generate troops or repeat automatically. FIRE starts ON; its existing OFF toggle is only a deliberate kiting stress control. Standard pause, level-up, background, death/revive, restart and Title controls remain.

The lab displays the actual profile/interval, startup/timed placement outcomes, live ambient/packet/source counts, and suppressed attempts. Read-only input-test probes additionally expose actual XP/level offers and their screen positions for native acquisition tests; they do not inject cards, change availability, select upgrades or change stats. Native tests make ordinary picks through touches.

## Timing and placement contract

Baseline uses the existing `WaveManager.currentSpawnInterval`. Trial multiplies that interval by0.8: initial1.20→0.96seconds, phase-one floor0.55→0.44, late floor0.25→0.20. The90second transition and existing65/105second floor times remain on actual game time. Actual arrivals need not increase exactly25%: frame quantization, the unchanged ordinary thinning/selection and blocked safe positions affect placement. More kills may also increase XP/levels per minute; rewards per kill are unchanged.

A preview-owned clock consumes the actual interval and active dt, at most once for each WaveManager elapsed step. It emits at most one attempt per update and resets its accumulator, with no overdue queue or burst. The main WaveManager still advances exactly once with actual dt; only its ordinary spawn boolean is replaced in this explicit mode. Ability-based spawn suppression consumes attempts without creating actors. Normal gameplay holds freeze the driver. No elapsed-time multiplier, global Wave constant, HP/XP/body/speed progression, attack timing or command-warning change is made.

Both profiles use the same safe floor/player-clearance and living-enemy-body overlap rejection, evaluated at the Float root SpriteKit stores and the final scaled footprint. Ambient candidates keep the existing current/neighbor-room rotation. A packet is all-three-or-none, and individual packet positions must also clear each other. Failures defer; they never create partial membership, use circle fallback, remove existing actors/XP or grant replacements. Ordinary crowding and pursuit after spawning remain possible: this is not a new collision or formation system. There is no new arbitrary total-enemy cap.

The old ordinary six-room/two-room and controlled-only labs retain their existing rules. Production Arenas1–7/BossMode, the enlarged map, card availability, save/service isolation, Arena9/10 and release metadata remain outside this change.

## Qualification and gates

The host harness tests fixed-profile scheduling and invalid/boundary/held/large-dt behavior. A separate differential compiles the actual unmodified WaveManager and extracted current constants, substituting only its SpriteKit import with Foundation; it compares emitted events and real elapsed/bell state. Compile errors and crashes never count as caught faults.

Actual Scene API tests cover both profiles, a real Title startup,125active-second controlled scheduling, event/outcome partitioning, no duplicate dispatch, spawn/player/body safety, all-or-none packet placement, existing-group commands amid ambient actors, all14 directed doorway routes using actual AI/resolver steps, control/ability holds, ordinary kill rewards and real XP/upgrade/lifecycle handlers. API placements, clocks, direct handlers and modal completion are labelled separately from native physics/input evidence.

Fresh phone/iPad native tests must exercise each launch profile with normal hostile damage: manual packet/source/SIGNAL, positive warning/pause observations, real kiting, gun kills/XP, actual upgrade picks and Title reset. Existing Scene and host regressions must remain attributable, with known catalog5/Void2 baseline guard failures explicit. Runtime qualification, exact frozen-candidate independent review and separate ACP are required. No owner feel, physical-device, FPS/Switch or final balance acceptance is inferred.

Natural packet distribution/cost, introduction/replacement caps, autonomous command cadence, final pressure tuning and Lockmarshal remain subsequent decisions. No production rollout, Arena9/10 work or App Store action belongs to this slice.
