# Arena 8 combat bridge — owner preview

In the shared Sparkforge Xcode project: scheme **Sparkforge**, Run configuration **Debug**, any available iPhone or iPad Simulator. Under Edit Scheme → Run → Arguments Passed On Launch, uncheck the old lab arguments and enable only `--arena8-combat`. Command-R. This is a separate opt-in scene; ordinary Run without a lab argument still opens the game normally. Remove/uncheck the argument afterward. Do not enable `--arena8-combat-checks` for the feel test (automated test runner only).

- Joystick moves the real Spark; the camera follows at 1×. Kite the existing basic grounded enemy between both rooms through the open corridor. Slide along walls and reverse at doorway corners.
- **FIRE** toggles automatic base shots. It starts ON; turn OFF for extended kiting. Ordinary auto-aim requires line of sight and range; **LS** toggles Long Shot T4 terrain passage/unlimited range/pierce-all, with no other cards. Existing airborne shots retain their launch policy.
- **SHOVE** is a test-only straight rightward displacement: a wall stops it; it can cross the open corridor. It never wraps around a corner.
- A kill drops a real XP orb; approach to collect. XP banks in the real ledger, but this controlled-loadout scene has no drafts/stat grants. **SPAWN** adds one replacement existing enemy after a kill, only at a valid sufficiently clear authored position; it cannot duplicate a living enemy.
- **PAUSE** holds actors, shots, XP and clocks; resume without catch-up attacks. Background/foreground preserves manual pause. **RESET** clears the lab and restores base HP/loadout/XP. Death stops play; RESET starts fresh.

Owner gate: movement, doorway combat/kiting, camera, shots/Long Shot and pause/reset feel on the owner's chosen device. Automated native checks are separate evidence; no physical-device performance or full encounter/content acceptance is implied.

No campaign registration, unlocks, save changes, new enemy/boss, production Rainbow, Arena 9 or publication. Accepted two-room P0 remains a foundation; the eventual Arena 8 floor targets at least roughly six rooms, to be authored only after layout/activation/roster/boss decisions.
