# Sparkforge v2.0.1 — Hotfix Sprint Kickoff

*Drafted Aug 2026, the week v2.0 went LIVE. Two items: a prod-blocking
progression bug and one fairness fix promoted from the field. Ships as
**2.0.1 (8)**.*

## Context

v2.0 cleared review and is live. Brandon's live playthrough surfaced both
items in one session — including an organic panda encounter in which the
samurai one-shotted the Arena 4 boss on spawn (working as designed, gloriously).

## The bug (found in prod, invisible in dev)

**Arena 5 is un-unlockable in the live build.** Root cause chain:

1. `spawnFacetedLie`'s `onDeath` (GameScene) never sets `arenasUnlocked = 5`.
   Every other boss handler has its unlock line; Arena 4's boss just doesn't.
2. The locked-card requirement switch (TitleScene) tops out at `arena3Gate`,
   so Arena 5's locked card mislabels its gate as "The Dynamo Choir".
3. The title-card boss map ends at `case 3` with an empty next-arena (v1.x
   leftover from when Arena 4 was last), so Arena 4's card can't announce
   "THE STAR ANVIL OPEN" either.
4. **Why no one ever saw it:** a `#if DEBUG` dev aid from v2.0 Unit 2a
   force-unlocks ALL arenas in every debug build ("live wiring lands when
   Unit 2 is complete" — it never landed). Every sim/device pass ran with
   Arena 5 pre-opened. The release binary was the first build to run the
   real progression. New canon example for the debug-seams rule.

## Decided — do not relitigate

- **The camera reveal ships in 2.0.1, not v2.1** (Brandon delegated the
  sizing call; decision: it fixes a live fairness issue, hooks a single
  choke point, and rides the same review cycle). If Unit 2 fights back,
  it drops to v2.1 without holding Unit 1 hostage.
- Save repair uses `hasDefeatedBoss("faceted_lie")`, inheriting its legacy
  kill-based fallback — same compromise v2.0 already accepted for Boss Mode.
- The DEBUG force-unlock is REMOVED, not gated — debug builds must run the
  real progression from now on.

## Unit 1 — Arena 5 unlock hotfix

1. `spawnFacetedLie.onDeath`: add the `arenasUnlocked < 5 → 5` line
   (mirrors the Dynamo Choir handler exactly).
2. `ProgressionManager.init`: retroactive heal, following the v1.7 Warden
   migration precedent — `hasDefeatedBoss("faceted_lie") && arenasUnlocked
   < 5 → 5`. Fixes Brandon's live save and every affected player on next
   launch.
3. TitleScene locked-requirement switch: explicit `case 3` (arena3Gate) +
   `case 4`/default → `arena4Gate` ("The Faceted Lie").
4. TitleScene boss map: `case 3` gets `nextArena: "THE STAR ANVIL"`;
   new `case 4` = ("The Unmade Star", last-arena, "unmade_star", `0x9A7AE0`)
   with honor text `★ THE STAR IS UNMADE ★` (**copy = Brandon's call at
   validation; placeholder until his pass**).
5. Remove the TitleScene `#if DEBUG` force-unlock block.
6. Version → 2.0.1, build → 8.

**DoD:** build clean, zero new warnings. Deterministic sim validators
(Claude): seeded save (faceted_lie felled, arenasUnlocked 4) heals to 5 on
launch and the title shows Arena 5 unlocked; fresh save shows Arena 5 locked
with "fell The Faceted Lie to unlock". Brandon: live-save device pass —
Arena 5 opens on update, plays end-to-end.

## Unit 2 — Boss-spawn camera reveal

Sequence on boss spawn: brief field pause → camera pans to the boss →
holds a beat → pans back to Spark, then gameplay resumes. Player learns,
simultaneously: something big happened, WHERE it happened, and what to do
about it. Kills the "Slag Titan steamrolls in from off-screen" unfairness.

- Hook: the common boss-spawn path (`showBossEntrance` call sites — all
  bosses funnel through it, monument bosses included).
- All timings/distances in `GameConfig` (pan duration, hold, ease).
- Must not fight: pause menu, ad-revive flow, Boss Mode back-to-back
  spawns, off-arena monument framing.
- **DoD:** build clean; no-softlock static checks (pause/resume during
  reveal); Brandon feel pass owns the timings — they are feel constants,
  chosen on device, not by reasoning (see the art-playbook lesson).
