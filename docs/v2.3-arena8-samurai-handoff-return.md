Both guards run before the stationary action. If a malformed state cannot resolve a floor root, only that visitor loses its actions/node/array entry before any strike/bow/reward. This follows the existing defensive failed-rest cancellation and frees its cap seat. The normal finite authored floor retains its existing fallback. It is not general corrupted-approach recovery: a nonfinite root with a live mark need not finish the original waddle, so the handoff guard is not claimed to repair every such in-flight state.

The existing ordinary arrival helper remains unchanged and continues excluding Samurai; the new guard follows it before the first act. The lost-mark guard runs before bow/one-second linger. Delayed strike still revalidates its original live mark and attacks at its current position, with original boss-class execution/scaling and remote slash behavior. Strike/bow do not move the root. Circle/two-room/Release and the published fear adapter stay unchanged. Root clearance is not complete containment of the wide painted sprite.

## Separate inherited pause finding

**The original strike can complete during the manual pause menu while dt-driven phase timers stop.** Both final Scene reports record `manualPauseStrikeCompletes: true`; the explicit inherited-behavior observation is among the341 checks, not a claim that pause semantics are correct or accepted. It does not invalidate the new root placement, but full Panda lifecycle cleanup remains open.

GameScene.pauseGame, PandaNode.strike, beginPandaAct and resolveSamuraiStrike are unchanged. A state-only pause does not pause the strike's SKAction. This was observed in the room run; the same source is shared with ordinary arenas, without claiming every arena/physical device was reproduced. No global action-pause rule, deferred hit or lost strike was silently introduced here.

Recommend a separate approved Samurai wind-up/cleanup package defining active-time holds, one-time resumption with remaining wind-up, original-mark revalidation and terminal cancellation. Manual pause, level-up/reveals, background, death/revive and reset/Title must be reconciled before changing shared behavior. This proposal is not implementation authority or a hidden card exclusion.
