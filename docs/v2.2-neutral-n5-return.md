### 2.3 Behaviour changes the reviewer should know (all required by R6 or the brief; none decided anew)
1. **Chain kills now cascade.** Legacy victims died uncredited and fell to the `.sweep`, so they never burst.
2. **Reward-only roots burst too.** Legacy burst only on full-credit deaths.
3. **An arena boss's death no longer bursts.** The legacy `resolveDeathBursts` ran for bosses; the brief excludes the arena boss as emitter.
4. **A distinct enemy standing exactly on the death position is now hit.** Legacy excluded it by position.
5. **Mini-bosses take half** (legacy: the full 1).
6. **Under a vulnerability, the single chance-rounding replaces the node's `Int((1 × v).rounded())`.** Expectation is preserved; for example, ×1.5 is no longer always 2 (checkpoint D4).
7. **The burst runs at the end of the frame instead of inside the killing call.** Same frame; no timer.

### 8.1 The repair: a narrow entry contract (checkpoint D2a)
- For a RESOLVED direct hit, EnemyNode reads `basis` for exactly one thing: Whiteout's melt test, plus the elite-melt path that rebuilds the hit around it. Health loss is `dealt` (verified in `takeDamage(_:resolved:)`; Spurhound/Ramplate pass `basis` through).
- So `ChainReaction.entry(_:)` delivers a positive resolved hit with a basis of at least 1: `dealt > 0 && basis == 0 → (1, dealt)`. Otherwise the hit is unchanged.
- `chainReactionBurst` delivers `ChainReaction.entry(hit)`.

What is preserved:
- `dealt`, the fractional budget, is unchanged: the fresh per-victim threshold, the mini-boss half and the vulnerability once.
- A true zero stays zero: no hit, no flash, no melt. With vulnerability ≥ 1 on one threshold, dealt ≥ basis, so dealt 0 ⇒ basis 0.
- The existing elite melt applies once: the extra 200 lands through the plain entry at ×1.2, giving 240.

Unchanged: EnemyNode, every other source's entry, tier/radius/credit/FIFO/ancestry and the rest of R6. No product fork arises.
