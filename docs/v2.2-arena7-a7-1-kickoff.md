Status: authorized implementation slice, October 16, 2026. Brandon approved the three Twin Channels calls and this first slice through Command Center. The [design proposal](v2.2-arena7-twin-channels-proposal.md) remains the design reference; its original proposal-only status records the earlier stage, superseded for A7-1 by this authorization.

- Existing melee enemies first; no new enemy, boss, public arena registration, unlock, reward, save key or release work.

- Automated and independent checks at technical checkpoints. Remaining owner hands-on checks batch into the integrated v2.2 pass with arena/enemies/boss/play systems. No fragmented human gate without a concrete blocking dependency.
- No commit/push/publication authorization. Preserve all unrelated working/staged changes, especially icons.

## Unit and implementation boundaries

One unit: A7-1 fixed geometry shell, transient DEBUG settings access and HUD announcement, restrained silhouette/route marks, safe existing-melee rim spawns, and clearance-aware routing. The preview is absent from `ArenaConfig.all` and BossRegistry. Campaign unlock healing remains six arenas. No boss/mini-boss in the shell. Boss Mode must ignore preview selection when choosing a real home arena.

Existing geometry supports arrays but shipped steering uses a greedy visible-node distance, not graph distance. The shell opts into a small authored-graph shortest route; existing arenas retain executed baseline steering. This is a bounded ten-node route policy, not a navmesh or general engine rewrite. Route decisions and exact visibility use each actor’s clearance. Safe spawn selection rejects geometry, boundary overflow, nearby Spark and crossing mouths; an unsafe preferred-lane draw defers to a later scheduled spawn tick rather than placing at an anchor. There are no new hostile area hazards in this slice.

Homes: ArenaGeometry.swift (descriptor and pure route/spawn policy); ArenaConfig.swift (DEBUG descriptor and transient override only); GameConfig.swift (spawn tuning); GameScene.swift (shell motif, DEBUG existing-melee spawner, dispatch/boss suppression and opt-in steering); GeometryDebug.swift and SettingsMenuNode.swift (existing DEBUG picker); tools/arena7-harness (executed seam checks). No project-file/icon edits.

## Definition of done

1. Descriptor dimensions, three clear crossings, ten nodes/eleven edges/four deployment arcs, and valid start anchor match approved layout; actual actor radii clear routes at phone/iPad inputs.
2. Real scene steering executes all-pairs lane-section goals at slow/fast frame steps, including displacement recovery, without trapping/oscillation. Graph connectivity alone is insufficient.
3. Actual spawn function emits only valid existing enemies, alternates safe lane preference, and defers unsafe draws without fallback. No new hazard claims.
4. Six existing arenas retain exact steering behavior against a frozen executable reference from `fb680ef608ffc2c86cee862b18698f4d9bfd50a1`; old geometry/Neutral/catalog regression stays intact.
5. DEBUG and Release compile with no introduced warnings; actual registry and preview/Boss Mode boundaries checked. No interactive app play required in this unit.
6. Independent review of a precisely identified candidate, resolve material findings, then report the reviewed candidate and remaining human QA. Do not publish automatically.

## Validation plan and limits

`tools/arena7-harness/run.sh` compiles production ArenaGeometry/ArenaConfig and extracts live scene steering/spawning/selection functions verbatim. SDK containers and enemy route-state storage are stand-ins; it proves route decisions/placement, not SpriteKit rendering, actual body motion, interactive input or device feel. Run existing geometry, Neutral and catalog harnesses for touched integration seams. New focused mutation controls should verify graph clearance, spawn rejection and preview isolation assertions detect relevant defects. Run builds sequentially with bounded CLI concurrency. Human readability/feel/performance stays for integrated v2.2 playtest unless technical evidence identifies an earlier blocker.
