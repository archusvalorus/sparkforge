## The formula, as implemented

Exactly §D, with two build notes:

- **Legacy parity by construction.** The % layer multiplies in the same
  order with the same float ops as the pre-A0 `applyPlayerDamage`, so every
  hit the ceiling doesn't clamp resolves to the identical number. P1 sweeps
  137,904 hit combinations against a transcription of the `0806262` code.
- **Clamped hits snap to micro-units** so float noise can't truncate the
  ceiling's own number (100 × (1 − 0.9) is 9.999…, which `Int()` makes 9).
  Only the new clamped path is affected.

**Where the ceiling actually binds in today's game:** only inside a kaiju
window stacked with more reduction — kaiju + Unyielding (92.5%) or kaiju +
≥35% of Forge Path bucket (e.g. Last Stand + Braced Impact = 90.25%).
Kaiju + Braced Impact alone (88.75%) is untouched. After A5, Ironhide at
10+ enemies reaches the ceiling by itself.

## Recon findings (Sep 15, from source)

- **F1 · Kill credit duplicates — 4 paths** (all verified against source):
  - **B1** `updateEnemies` removes DoT deaths by a stale index: an on-kill
    burst (Ember Burst / Open Vein) re-kills another dying enemy and
    shifts the array, so the wrong, LIVING enemy gets removed + credited
    and left frozen in the scene. If the burst empties the array enough,
    `enemies[index]` is out of range — **a crash. This code is identical
    in live v2.0 (`v2.0-build7`) and `v2.0.1-build8`.** Trigger: two
    enemies die to DoT in the same frame and the first one's burst reaches
    the other (e.g. the last two burning enemies, Ember Burst owned).
  - **B2** Forge Path Overkill bursts at the dead enemy's own position
    before it leaves `enemies` → double XP on every Overkill proc.
  - **B3** Iron Bloom kill, then Thornwall + Iron Maiden Thorns/Retaliate
    re-hit the same body → up to 4× credit.
  - **B4** `fireRiftCannon` credits outside its removal guard → double
    credit when a burst killed the next target first.
  - Root: `EnemyNode.takeDamage` has no `isDying` guard, so a dead enemy
    returns "killed" again and restarts its death animation.
- **F2 · The Slag Titan slam bypasses the player guards.** `onSlamHit`
  checks only `damageCooldownTimer` — no i-frames/invulnerability, Silver
  Skin, Phase Skin, or Overcharge reset. The approved order says explicit
  invulnerability ignores a contact before step 1.
- **F3 · Two debuffs time out on real time.** Erasure Fracture and Polar
  Vortex Frostbite reset `vulnerabilityMultiplier` from `SKAction.wait` on
  the enemy node. Pause and level-up only change `gameState` — the world
  keeps running — so both windows expire while the player picks a card.
  Every other enemy status already ticks on game dt.
- **F4 · Shared vulnerability slot (legacy, not changed).** Skybeam Called,
  Fracture and Frostbite all write one `vulnerabilityMultiplier`; last
  writer wins and a reset clears the others. Noted for A3/A6.
- **F5 · Iceburst can cascade uncapped** (shard kill on a slowed foe →
  another Iceburst). Legacy; `KillSource.fragment` is what A2 needs to cap
  it alongside CL-3's shard wiring.
- **F6 · Lost full credit (legacy, preserved):** batch loops skip an enemy
  a burst already removed — it gets the XP orb but no kill count, bestiary
  or arena gate. Matches the XP-only burst tier; not changed.

## Brandon's gate — what to feel for

A0 is plumbing: a normal run should play **exactly** like before. The
things that are meant to change:

1. **Brace still saves you.** Take Brace, get hit to death — you should
   survive at 1 HP with the flash and the enemy push-back, once. (The sim
   run never offered Brace; the harness proves the ordering, this proves
   the wiring.)
2. **Slag Titan's slam respects i-frames.** Right after a hit (or with
   Phase Skin / Silver Skin up), a slam shouldn't land a second chunk.
3. **Fewer duplicate XP orbs** with Forge Path Overkill, Iron Bloom +
   Thornwall / Iron Maiden, Erasure's Rift Cannon, and pairs of burning or
   bleeding enemies dying together near Ember Burst / Open Vein.
4. **Fracture and Frostbite pause with the game** — hard to feel; mostly
   a correctness fix.
5. **Kaiju windows stacked with Unyielding or heavy Forge Path DR** take
   10% of a hit instead of less — only if you happen to be in one.

Debug console: `[A0]` lines print on any Brace save or rejected duplicate,
and a one-line summary when the run ends.
