# Arena 8 packet command core — isolated preparation

The owner approved carrier/signaler/mobile Lockmarshal concepts and continuing bounded work on October 30. This unit prepares an inert run-owned command ledger before enemy integration. It has no Scene consumer, node class, spawn/timing/stat defaults, save writes or production registration. It neither implements the carrier encounter nor claims playable enemy acceptance.

The core stores UUID identities supplied by a future scene adapter, never EnemyNode references. A packet owns one carrier plus explicitly supplied escorts. Membership removal requires a captured generation/packet-incarnation/member ticket; actor UUID alone cannot tear down a later association. Registration is atomic and rejects duplicate ownership. Commands capture run generation, packet revision, source and connection identity. Only the carrier source is supported in this unit; signaler arbitration remains separate. Prepare, active-time advance and explicit commit remain separate. The caller supplies telegraph duration and revalidates destination geometry/live identities at prepare and commit. A hold freezes the clock; zero/invalid dt cannot advance it. No wall-clock timer or automatic commit exists.

Membership changes invalidate uncommitted work. Already committed navigation remains associated with its command identity and only surviving members; the core does not move actors, cancel attacks or make remaining members complete a migration. Owner removal releases surviving escorts and invalidates commands. Reset changes generation. All scene effects, body-safe local goals, ordinary combat targets and attack-phase permissions remain later integration work.
