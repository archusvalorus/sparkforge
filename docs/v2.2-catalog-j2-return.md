- **None material.** The plan's "startup presentation" was left open in D1 beyond "concise error screen, details in logs"; the screen built is the minimum: title, summary, hint, and (DEBUG only) the report. Its wording is Claude's and is a copy decision for Brandon if he wants it changed.
