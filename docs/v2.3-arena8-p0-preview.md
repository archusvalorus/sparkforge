# Arena8 P0 owner preview

Use Debug with `--arena8-p0` in Xcode Run scheme arguments. Remove that argument for the normal title; `--rainbow-p1` keeps its existing independent lab and has priority if both arguments are supplied. Release excludes both labs; catalog failure still blocks startup normally.

This is an isolated two-room geometry fixture. The fixed overview scales only its world artwork; the existing joystick/HUD keep normal screen coordinates. It is not the final map size, art, roster or production camera. Dark central blocks are solid; the middle corridor/doorways are permanently open. Route dots show authored corridor guidance. Spark is the small gold body; three grounded collision fixtures have radii14/26/40. They can overlap each other and Spark: combat, crowds, HP and contact damage are absent.

- Use the left joystick to walk Spark between rooms. Try doorway jambs, corners, dragging against walls, room edges and reversing pursuit. Large bodies use a validated reachable approach when Spark hugs a wall; they do not teleport.
- **PAUSE** freezes active movement/probe time. Backgrounding freezes too; returning does not clear a manual pause. **RESET** restores the fixture. **SHOVE** is a straight600pt displacement attempt to the right and stops before a wall; it is disabled while held. Walking slide and instant shove are intentionally separate seams.
- **LS** toggles Long Shot for the next captured wall probe. Every2 active seconds a ray is captured toward the right-room anchor. Red means wall-blocked and the visible ray stops before the wall; green means a clear/LongShot passage. This is an exact wall-hit probe, not a weapon or damage effect. A toggled setting never rewrites the previous captured ray.

Review smooth doorway/corner walking, pursuit/return and whether the two rooms support deliberate kiting. Native input/owner feel is a separate gate from host/native technical checks. Headless screenshot/video evidence, if captured, does not validate joystick or buttons. No device/Switch performance claim.

P0 includes an opt-in circle/rectangle bounds primitive in DEBUG only. It leaves real PlayerNode/GameScene/EnemyNode/spawners/projectile cleanup unchanged. Production bounds adapters, real AI/displacements/projectiles, pickups/XP, real Rainbow integration, camera progression, unlocks/rewards, bosses/roster and Arena9 encounters/goals/retirement require later bounded units.
