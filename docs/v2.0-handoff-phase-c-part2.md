## NEXT — three pieces, in this order

### 1. Nature Canon roster (systems) — `docs/nature-canon-roster-design.md`
The Tree's T5 launcher shipped with a PLACEHOLDER roster (5 emoji animals). The
real 10-animal roster is **designed and locked** in that doc. The one real
engineering task: **extend `TreeAnimal` from a data tuple to a BEHAVIOUR model**
(on-launch / on-impact), because homing / timed-turret / devour / propagating-

Skunk's poison-propagation is a genuine subsystem — build it CAPPED (v1), and it
becomes the Decay tree's foundation later.

### 2. Panda secret tree (C2) — `panda-secret-tree` memory

once taken, escalating to a flaming panda kaiju + a rare Panda Samurai that

FamiliarNode, morph, priority-target (the `findPriorityTarget` helper extracted
in Growth C1.3), execute, the tier engine, the conditional pool. The Growth
launcher + homing (Fox) work directly feeds the samurai.

### 3. THE ART PASS (after systems) — Brandon's call
Build #1 and #2 against **placeholder visuals** (emoji stand-ins, as Nature
Canon already does), verify the systems, THEN do ONE art-pass sprint that
replaces every placeholder at once: the 10 Nature Canon sprites, the Panda
kaiju/samurai, and the **premium/panda skins (C3)** together. Systems first so
art never blocks engineering; art bundled so it's one focused mode of work.

**Recommended sprint shape:** (Sprint 1) Nature Canon behaviour model + all 10
animal mechanics, placeholder art → (Sprint 2) Panda tree systems, placeholder
art → (Sprint 3) the art pass: Nature Canon + Panda + skins sprites. Units
within each still gate one-at-a-time with a Brandon device pass.

## Key context the next thread needs

- **The Tree launcher lives in `GameScene`** (`updateTreeCanopy`, `launchAnimal`,
  `spawnLionPet`, `Self.treeAnimals`). `TreeNode.swift` is the dumb-body visual.
  The scene owns targeting (`findPriorityTarget`) and effects; the node owns
  look — the same split the flowers use.
- **The reuse map is the point** (see the design doc): Fox→homing→samurai,
  Hedgehog→timed turret, Skunk→Decay, Deer/Boar→Repulse knockback, Badger→
  lifesteal, Bluebird→eruption AoE. Every animal is future plumbing.
- **Badger heal is boss-class scaled** via `GameConfig.BossClass` (100% normals,
  ≤50% boss-class) — same levers as capstone resistance.
- **Rabbit stays ridiculous** (~450% single hit) — intended, do not "balance" it.
- **Growth's dark sibling is Decay** — reserved, post-v2.0. Skunk seeds it; don't
  build Decay mechanics into Growth.
