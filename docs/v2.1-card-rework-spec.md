# Sparkforge v2.1 — Card / Ability Rework Spec

*Brandon's Card Atlas rework notes, reconciled against the live card pool
by Claude (Aug 2026). Working card-by-card, family-by-family. Status per
tree: 🟢 spec locked · 🟡 Brandon's notes in, reconciled, awaiting his
answers to the OPEN CALLS · ⚪ not yet reviewed. This doc becomes Lyra's
canonical ability-design packet (her reconciliation §8) once all eight
trees are done — the atlas regenerates from it.*

**Design theses (Brandon):** Fire = burning + big booms, with a real
risk/reward dial. Chill = control that escalates into transformation.
Shock = LOUD, bombastic, chaining wackiness — "wackiness is how we'll be
remembered." Cross-cutting: **each tree gets an explicit ENTRY POINT card**
(Kindle / Frost Touch / Chain Lightning) — the tree's baseline first
choice.

**Card-count deltas so far:** Fire 9→9 · Chill 8→8 (−Static Field, +Glacial
Spikes) · Shock 10→7 (−Arc Wake, −Live Wire, −Induction Step, −Copper Vein;
+Lightning Sentry, +Electro Pulse; Arc→Chain Lightning). Neutral/Bleed/
Guard/Void/Growth pending.

**OPEN CALLS — Fire**
- **Q-F1 (Forge Breath):** "fire damage" as a bucket doesn't exist — the
  engine has a global damage multiplier and burn DPS. Options: (a) Forge
  Breath scales **burn DPS + Ember Burst + Everglow** (everything Fire
  *owns*), or (b) it scales the projectile damage of *ignited* hits. (a)
  is cleaner and matches "burning + big booms." Recommend (a).
- **Q-F2 (Crucible stacks):** burn is one instance per enemy today. Stack
  model: does each stack add full Kindle DPS (linear, strong) or a
  fraction? Is there a cap (recommend 5)? Does the 3s be per-enemy or
  global? Recommend: per-enemy, +1 stack per Kindle hit at most every 3s,
  cap 5, each stack = full Kindle DPS. Big booms.
- **Q-F3 (Cauterize):** flat +5 HP per 3s ticks, or scale with max HP as
  the game grows (e.g. 3% max HP / 3s)? Flat is legible; % ages better.
- **Q-F4:** Overcharge unmentioned — keep as-is?

**CANON FLAG — Chill:** the card-leveling canon is "tiers 1/2/3/5, no 4;
tier 5 is a capstone and there is **one capstone per tree**." Glacial
Drift T5 (Ice Rink) is a 5-tier ladder with a capstone-grade payoff in a
tree that already has Polar Vortex — and Chain Lightning below is a
**4-tier** ladder, which the "no tier 4" rule forbids. Both are great
designs; the question is whether v2.1 **amends the canon** ("a tree may
carry ONE capstone plus signature multi-tier cards up to T5, and tier 4
is allowed") or the ladders compress (Glacial Drift 5→3 with Ice Rink as
a *conditional* T3, Chain Lightning 4→3). **Recommend amending the canon
— the rework is the moment to do it deliberately, and it also un-blocks
Lightning Sentry's 4 tiers.** Your call, and it goes in the Decision Log.

**OPEN CALLS — Chill**

- **Q-C3 (Snowmen):** stun/transform proc rate — proposal 12% on hit,

## Cross-cutting engineering notes (for the build, not blocking design)

- **Entry points**: implement as a soft weight in the draw (entry cards
  offered first in a tree, before non-entry cards) — NOT a hard gate,
  or a tree's palette slot could show nothing. Extends the existing
  eligibility layer's soft-weight path; no new system.
- **New FX debt for Lyra/art**: dazed stars (Overload), snowman + melt
  puddle (Whiteout), louder chain-lightning + synergy VFX, Static Crown
  ring, Tesla coil sprites/electric arcs, Ice Rink floor treatment.
- **Codex**: 6 removals + 4 new cards + 1 rename → the Cards codex page
  and any lifetime "discovered" records need a migration note
  (`sf_` keys never renamed — new ids for new cards, removed ids simply
  stop rendering).
- **Boss Mode**: 1HKO spikes + snowman stuns need `BossClass` scaling —
  both already flagged boss-reduced above.
