# Sparkforge v2.1 — Card / Ability Rework Spec

*Brandon's Card Atlas rework notes, reconciled against the live card pool
by Claude (Aug 2026), then RESOLVED by the Brandon × Lyra twofold review
(`docs/v2.1-ability-decisions-handoff.md`, Sep 15 2026 — all 28 numbered
calls answered, canon amended). Status per tree: 🟢 decided · 🟡 awaiting
answers · ⚪ not yet reviewed. What is still open lives in ONE place:
`docs/v2.1-ability-closure-table.md`. This doc becomes Lyra's canonical
ability-design packet (her reconciliation §8) once the seven trees are
built — Neutral is postponed to v2.2+ and the atlas regenerates without it.*

**Precedence:** where a DECIDED block below conflicts with an older
recommendation in the same section, the DECIDED block wins. Unchanged
card behavior stays unchanged unless a decision here says otherwise.

**Design theses (Brandon):** Fire = burning + big booms, with a real
risk/reward dial. Chill = control that escalates into transformation.
Shock = LOUD, bombastic, chaining wackiness — "wackiness is how we'll be
remembered." Cross-cutting: **each tree gets an explicit ENTRY POINT card**
(Kindle / Frost Touch / Chain Lightning) — the tree's baseline first
choice.

**Card-count deltas (recomputed Sep 15 from the tables below):** Fire
9→9 · Chill 8→8 · Shock 10→8 · Bleed 12→13 · Guard 10→10 · **Void 12→13**
(the Aug header said 12→12 — wrong) · Growth 8→8 (untouched) · Neutral

Taxonomy: **seven affinity trees + Neutral** (audit any stale "eight

**BLEED MATH (Brandon asked):** current model = `bleedDPS` accrued
continuously for `bleedDuration`; Needlepoint's source was +0.5 DPS. For a
ticking model, tie the tick to ATK rather than a flat 1 HP, or it stops
mattering by level 10 (enemy HP scales; Spark's ATK starts at 10):

| Option | Tick | Interval | Duration | Total / application | Feel |
|---|---|---|---|---|---|
| A (flat, as written) | 1 HP | 0.5s | 4s | 8 | legible early, irrelevant late |
| **B (recommended)** | **10% ATK** (=1 HP at start) | **0.5s** | **3s** | **60% ATK** | reads as "1 HP" on day one, scales forever |
| C (heavier, fewer) | 25% ATK | 1.0s | 3s | 75% ATK | chunkier hit-feel, easier to see numbers |

Re-application **resets duration, doesn't stack** (stacking is Crucible's
job in Fire; Glass Blood + Open Wounds are where Bleed's amplification
lives). At 50% apply chance with ~2 shots/s, a target is bleeding nearly
continuously — so B's 60% ATK per application ≈ +20% sustained DPS on a
single target before synergies. That's a fair signature.

**DECIDED — Bleed (Sep 15)**

  **Q-B3** barrier rules · **Q-B4** Red Smile as in the table ·

  written in the table rows above.

  finishing-blow rule are additionally approved (see rows).
- **NOT approved (pending):** the Bloodthirsty tick model — Option B

  stacking or postponing the next tick; = 20% ATK/s while active; 1 HP per

  change the build waits on.

**Engineering note — consolidate the black hole.** After this pass FIVE
things are black-hole-shaped: Gravity Well (card), Null Bloom (small),
Dead Circuit (grown), the Blackhole synergy (every 5th shot), and
Singularity's decompose. Today Gravity Well = `spawnGravityWell(radius,
duration, dps)` — already a parametric node. **Build ONE `VoidWellNode`
with parameters (radius, duration, pull, absorbsProjectiles,
relaunchesProjectiles, stuckOnEntry, decomposeDPS, growthPerConsumed,
collapseCount) and express all five as presets.** Otherwise the tree
ships five slightly different holes. This is the Void equivalent of the
unlock registry.

**DECIDED — Void (Sep 15)**
- **Q-V1 / Q-V2 / Q-V3 / Q-V5:** as in the table rows.
- **Q-V4:** wells absorb **HOSTILE projectiles only** (Brandon explicit).
  Working recommendation, NOT separately approved in every detail:
  absorbed shots relaunch from the well toward the nearest valid enemy as
  player-owned Void projectiles; no friendly re-absorption, no
  self-feeding loops; returned shots get applicable Void damage /
  penetration / Anomaly but never advance primary-shot counters or spawn
  further projectiles. Closure table enumerates the allowed interactions
  for confirmation.

## Cross-cutting engineering notes (for the build, not blocking design)

- **Entry points = SIGNATURES, HARD-GATED.** (Supersedes the Aug
  "soft weight" line, which is stale.) The authority is
  `docs/v2.1-signature-cards-spec.md` + the shipped draw mechanics

  new decisions):** tier percentages are TOTALS, not additive grants;
  attack-speed percentages describe firing-rate increases (interval

- **New FX debt for Lyra/art**: dazed stars (Overload), snowman + melt
  puddle (Whiteout), louder chain-lightning + synergy VFX, Static Crown

  and any lifetime "discovered" records need a migration note
  (`sf_` keys never renamed — new ids for new cards, removed ids simply
  stop rendering).
- **Boss Mode**: 1HKO spikes + snowman stuns need `BossClass` scaling —
  both already flagged boss-reduced above.
