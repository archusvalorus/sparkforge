# Sparkforge v2.1 — Card / Ability Rework Spec

*Brandon's Card Atlas rework notes, reconciled against the live card pool
by Claude (Aug 2026). Working card-by-card, family-by-family. Status per
tree: 🟢 spec locked · 🟡 Brandon's notes in, reconciled, awaiting his
answers to the OPEN CALLS · ⚪ not yet reviewed. This doc becomes Lyra's
canonical ability-design packet (her reconciliation §8) once all eight
trees are done — the atlas regenerates from it.*

**Design theses (Brandon):** Fire = burning + big booms, with a real
risk/reward dial. Chill = control that escalates into transformation.
Shock = LOUD, bombastic, chaining wackiness — "wackiness is how we'll be
remembered." Cross-cutting: **each tree gets an explicit ENTRY POINT card**
(Kindle / Frost Touch / Chain Lightning) — the tree's baseline first
choice.

**Card-count deltas:** Fire 9→9 · Chill 8→8 · Shock 10→8 · Bleed 12→13 ·
Guard 10→10 · Void 12→12 · Growth 8→8 (untouched) · Neutral pending. Eight
removed, eight added across the six reworked trees.

**BLEED MATH (Brandon asked):** current model = `bleedDPS` accrued
continuously for `bleedDuration`; Needlepoint's source was +0.5 DPS. For a
ticking model, tie the tick to ATK rather than a flat 1 HP, or it stops
mattering by level 10 (enemy HP scales; Spark's ATK starts at 10):

| Option | Tick | Interval | Duration | Total / application | Feel |
|---|---|---|---|---|---|
| A (flat, as written) | 1 HP | 0.5s | 4s | 8 | legible early, irrelevant late |
| **B (recommended)** | **10% ATK** (=1 HP at start) | **0.5s** | **3s** | **60% ATK** | reads as "1 HP" on day one, scales forever |
| C (heavier, fewer) | 25% ATK | 1.0s | 3s | 75% ATK | chunkier hit-feel, easier to see numbers |

Re-application **resets duration, doesn't stack** (stacking is Crucible's
job in Fire; Glass Blood + Open Wounds are where Bleed's amplification
lives). At 50% apply chance with ~2 shots/s, a target is bleeding nearly
continuously — so B's 60% ATK per application ≈ +20% sustained DPS on a
single target before synergies. That's a fair signature.

**OPEN CALLS — Bleed**
- **Q-B1:** Frenzy duration (notes say "for s") — recommend **4s**.
- **Q-B2:** Berserk curve — linear to +50% atk spd at 0 HP? Or a floor

- **Q-B3:** Blood barrier = a shield HP pool absorbing damage before HP.
  Cap? Recommend cap at 50% max HP so Siphon-overheal can't make Spark
  immortal; barrier does NOT trigger Brace/Phase Skin (it's pre-HP).
- **Q-B4 (Red Smile / Thing From Below):** melee = what? Proposal: an

  art). Does the 10s cycle run always, or only while a Void card is
  owned (dual-tag bridges need both colours active)? Recommend: the card
  is only offered when Void is in the palette (existing bridge rule) and

- **Q-B5:** Siphon 4 tiers → canon flag (amend, or 3 tiers 1/2/4).
- **Q-B6:** Bloodlust "+0.1% per bleed kill" — at 300 kills to cap, most

## Cross-cutting engineering notes (for the build, not blocking design)

- **Entry points**: implement as a soft weight in the draw (entry cards
  offered first in a tree, before non-entry cards) — NOT a hard gate,
  or a tree's palette slot could show nothing. Extends the existing
  eligibility layer's soft-weight path; no new system.
- **New FX debt for Lyra/art**: dazed stars (Overload), snowman + melt
  puddle (Whiteout), louder chain-lightning + synergy VFX, Static Crown
  ring, Tesla coil sprites/electric arcs, Ice Rink floor treatment.
- **Codex**: 6 removals + 4 new cards + 1 rename → the Cards codex page
  and any lifetime "discovered" records need a migration note
  (`sf_` keys never renamed — new ids for new cards, removed ids simply
  stop rendering).
- **Boss Mode**: 1HKO spikes + snowman stuns need `BossClass` scaling —
  both already flagged boss-reduced above.
