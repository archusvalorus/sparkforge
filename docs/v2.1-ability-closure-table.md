**Runtime facts from the A4c recon (HEAD `b29ccc1`, Sep 22). Each one changed or sharpened a row:**
1. **"Active combat" has one consumer today, and A5 will add the second.** At HEAD, Grounded Core is a 0.7s brace with no combat condition, and Fortify is a global 8% slow. The stand-still and in-combat versions exist only in the spec (A5). So the definition picked here is also A5's.
2. **The gun's target picker is not a clean "in combat" signal.**
   - Its 400pt range is not DeviceScale-scaled, and it grows with range cards.
   - It prefers the Skybeam lasso target.
   - It happily targets a phased PaneStalker or the vanished Faceted Lie. The shots just pass through.
   - It already holds fire when every enemy is behind the Carrier.
3. **Nothing marks intangibility except `physicsBody.categoryBitMask = 0`.** PaneStalker's phase and the Lie's vanish are both private, and death uses the same mask. Every non-physics effect already lands on both: DoTs, area bursts, the kaiju strike. The Lie's DoT-through-vanish is commented as intended. The sweep would be the first non-physics effect that deliberately respects intangibility.
4. **`lastMoveDirection` works as a facing vector, except it is never reset between runs.** It is unit length, starts straight up, updates only on stick input outside the dead zone, and survives release, pause and the boss reveal. Because `restartGame` never touches it, a new run faces wherever the last run ended.
5. **The kaiju runs every 55s start-to-start** (10s form plus a 45s gap) with no combat condition, on raw `dt` counters. While it is active it freezes the gun's `FireClock`, but nothing else: turrets, flowers, Iron Maiden and echoes keep going.
6. **Braceguard's shield tests where Spark stands** (`blocksHit(from: player.position)`), so a frontal sweep is exactly the case it halves. The only bypass today is Erasure's `erasureVoidTouched`.
7. **The projectile hit chain has about 25 inline steps.** The card copy splits them into two kinds: Kindle, Frost Touch and Repulse say "**Projectiles** …", while Overload, Whiteout and Chain Lightning say "**Hits** …".
   - The Apex and Erasure meters already have per-stack cooldowns, so registering once per target can't flood them.
   - `applyForgeOffense` has per-call side effects. Cold Fury and Killing Stroke charges are spent on the first target. Relentless resets whenever the target changes, so in a sweep it would reset on every hit.
8. **Crit and damage are frozen when a projectile is FIRED**: crit is rolled at fire time, and `damageMultiplier` includes Overcharge at fire time. A swing would read both live, per target.
9. **Radii:**
   - Enemies have no combat radius. The physics body is always 12pt, even on a mini-boss drawn at 2.2×.
   - Mobile bosses report `targetingRadius = 0`, so the gun and the kaiju measure them to their centre. Their bodies are 21–36pt.
   - The Unmade Star's surface radius is about 335pt.
10. **The Carrier is ~177pt thick** — *corrected in review:* the Splitworks radius is 350 × 1.15, and the rounded corners add 0.06r a side, so 0.44r ≈ 177pt, not 112. Against an 80pt reach, the terrain rule only bites around its rounded ends. **Also found in review:** the shared `segmentBlocked` marches at the footprint's half-thickness (~88pt), so any shorter segment is only tested at its endpoints and passes the rounded ends unblocked. The sweep therefore uses a new exact test (`segmentBlockedExact`); the shared one is unchanged (see the A4c return packet).
11. **Void's card colour is purple (0x9944CC).** In-world purple is locked as DANGER (enemy shots and ranged enemies).
12. **`KillSource.sweep` already exists** as the reward-only dying-enemy prune, so the new case has to be `.melee`.
13. **Base numbers:**
    - fire interval **0.5s**
    - projectile damage **1** (`damageMultiplier` 1.0)
    - `shotFractionDamage(2.0)` = **2**
    - crit ×2.0
    - Bleed tick **1 per 0.5s for 3s**

    A 3s form at base swings **6 times**.

**FINAL RULINGS (Brandon, Sep 22). These WIN over the draft table below wherever they differ.** Recon findings stay authoritative inputs. Approved: CL-34, 35, 36, 37, 38, 40, 41, 43, 45, 46, 47 (some with a clarification or default). **Modified:** CL-33, 39, 42, 44, 48. Scope: implement A4c only; no A5, A6, A7 or unrelated cleanup.

- **CL-33 Active combat — MODIFIED.** Active combat means **at least one currently hittable hostile enemy or boss exists in the active encounter.**
  - Distance, line of sight and gun targeting range do NOT matter.
  - Phased or vanished enemies do NOT qualify.
  - After the last qualifying hostile stops qualifying, active-combat state holds for **0.5s** before dropping.
  - Hiding behind the Carrier is NOT leaving combat while valid hostiles still exist.
  - Shared infrastructure: Red Smile now, Grounded Core in A5.
- **CL-34 Cycle — APPROVED.** A 10s start-to-start cycle, measured only during active combat.
  - The first transformation comes after 10 accumulated seconds of active combat.
  - Lulls pause the cycle; they never reset it.
  - The cycle restarts at each transformation start.
  - The transformation always gets its full 3s, unless another approved mechanic (the kaiju) ends it.
- **CL-35 Facing — APPROVED WITH DEFAULT.** Normalized `lastMoveDirection`, which holds where the player last moved when the stick returns to neutral.
  - Reset every run, so it can't carry across restarts.
  - Default is the deterministic up-screen `(0, 1)` until the player gives movement input.
- **CL-36 Damage — APPROVED WITH CLARIFICATION.** Each sweep target receives `shotFractionDamage(2.0)`: twice the current projectile/shot damage, **not** 200% ATK.
  - Crit rolls independently per target.
  - Every surviving target gets guaranteed Bleed.
  - Bosses and mini-bosses get the same damage basis as ordinary targets, with no special Red Smile penalty.
  - Ordinary applicable direct-hit defenses still apply, unless an explicitly approved Red Smile/Void rule bypasses them.
- **CL-37 Void damage — APPROVED.** In A4c, Red Smile's Void damage has ONE special consequence: it bypasses the Braceguard directional shield. Void affinity does not automatically bypass unrelated defenses, terrain, walls, collision or other mechanics.
- **CL-38 Terrain — APPROVED.** Red Smile does not sweep through the Carrier; its geometry blocks the attack normally. This is independent of Void affinity.
- **CL-39 Hit semantics — MODIFIED.** A sweep is a **primary attack**, and each enemy struck receives a **primary hit**. A swing is **not a projectile** and **not a shot**. Therefore:
  - Hit-based, primary-hit, and hit-qualified status/damage effects may trigger per target.
  - Projectile-only effects do NOT trigger.
  - Shot counters do NOT advance.
  - Effects that spawn or modify additional projectiles because a shot occurred do NOT trigger.
  - Forge offense charges and Apex/Erasure-style hit meters keep their normal per-hit semantics, so striking several targets may advance them several times where their contract is hit-based.
  - **Chain Lightning triggers at most once per swing**, however many targets are struck.
  - Classify effects by their text/contract semantics; never infer eligibility from where the code happens to sit.
- **CL-40 Phased/vanished — APPROVED WITH GUIDANCE.** Red Smile never strikes phased or vanished targets.
  - Use an explicit SHARED hittability state/predicate, suitable for both Red Smile and CL-33, rather than Red-Smile-specific logic.
  - Do not repair the gun's targeting of phased/vanished actors in A4c unless compilation or contract integrity requires it. Track it separately.
- **CL-41 Reach and arc — APPROVED WITH GEOMETRY CLARIFICATION.** 110° arc, 80pt reach, with **body-radius-aware sector overlap**.
  - Reach is measured against the target's occupied body, not its centre, and angular overlap naturally accounts for wide targets.
  - No per-boss special cases, and no arbitrary global angle expansion for size.
  - The Unmade Star and other wide actors are hit when their physical footprint genuinely overlaps the sweep sector.
- **CL-42 Swing cadence — MODIFIED.** Red Smile owns a SEPARATE melee clock that reads the SAME shared effective attack-rate calculation as the gun, so all approved attack-speed modifiers apply.
  - The first swing comes immediately when the form begins; later swings follow the effective interval. That gives **six swings in a 3s form at the 0.5s base**.
  - Empty swings still happen.
  - Keep a bounded timing remainder as appropriate.
  - **NO 0.10s minimum interval in A4c.** The true-rate philosophy stands: stress-test the uncapped calculation first, and add a floor only with device/performance evidence plus Brandon's approval.
- **CL-43 Gun during the form — APPROVED.** Primary auto-fire pauses. Its firing-clock remainder freezes, with no shot debt accruing while paused, and the gun resumes from that preserved state when the form ends.
  - Do not disable `fireProjectile` globally.
  - Existing projectiles, fragments, echoes, turrets, summons and other independent sources continue under their existing rules.
- **CL-44 Kaiju overlap — MODIFIED.** The kaiju has priority.
  - If the kaiju activates during Red Smile, Red Smile ends immediately and the kaiju proceeds normally.
  - While the kaiju is active, the Red Smile cycle clock pauses, and no transformation begins, banks or queues.
  - When the kaiju ends, Red Smile resumes from its remaining cycle time if active-combat conditions are satisfied.
- **CL-45 Tree identity — APPROVED.** It counts as both a Bleed and a Void card and feeds both ladders. It stays one card and one pool entry, with no count increase. Eligibility still requires both unlocks.
- **CL-46 Defense and movement — APPROVED.** Attack mode only. It inherits none of the kaiju's slowdown, damage reduction or other defensive behaviour.

  - Near-black Spark with a crimson grin.
  - A readable facing indicator/arc.
  - A crimson crescent per swing.
  - A lightweight RED SMILE timing/countdown treatment readable on device.
  - **No Void purple on the transformed body** (purple = danger).
  - Final production art is a later art/closeout concern.
- **CL-48 Card text — MODIFIED.** Face: **"Every 10s: 3s of Void melee. 2× damage + Bleed."** Detail = the previously approved copy, then: **"Sweeps strike in your last move direction. They count as primary hits, not shots or projectiles."** Never use broad copy like "carry your on-hit effects".

**Runtime facts from the A6 recon (HEAD `1394bf1`, Sep 24). Each one changed or sharpened a row:**
1. **Gun damage is a whole number, and it is almost always 1.** A hit deals `max(1, Int(damageMultiplier))`, snapshotted at fire time. `damageMultiplier` starts at 1.0 and rises only through Overcharge (≤ +0.5), Forge Path nodes (+1–1.5% each), Iron Skin, Everglow growth, the Unbroken window, and **Mass Tax (+0.30), which A6 removes: the pool's only card that raises it directly.** So every *shot-relative* percentage under 200% rounds away in a typical run: Warp's 150% → 1, Shadow Edge's 125% → 1, Riftline's falloff never shows (floor 1). "% ATK" abilities are a different scale: they read `baseAttack` (10, +5 per pick), so "150% ATK" = 15. (A1's ruling accepted truncation for the gun; A6 is the first unit whose card identity *is* a sub-200% multiplier.)
2. **No Void damage flag exists.** CL-37 was built as an omission: `redSmileHit` flashes the Braceguard shield but never halves (GS 11641). Erasure T2's bypass is a separate global bool checked at GS 11260 and 11806. The boss path never consults either, so nothing reaches the DEF dial. "Attach Phase T2 and Anomaly to the flag" means A6 creates the flag.
3. **The enemy side has exactly two defences.** (a) The **Boss Mode flat DEF dial**: `round(2 × def) − 2` per direct boss hit, floor 1. It is 0 at dial ≤ 1.0 and −2 at most, it's skipped when a raw hit ≥ current health, and the Marchwarden never gets it. (b) **Braceguard's shield**: ×0.5 on projectile hits within ±60° of its facing, tested from *Spark's position*. No boss has an armour phase, shield or damage-reduction state.
4. **"Elite" means mini-boss in code.** `isMiniBoss` is the only classifier; only `spawnMiniBoss` sets it (10 + 3 HP per 30s elapsed). The enemies whose comments say "elite" (Anvilborn, Echo Leech, Ramplate) are ordinary EnemyNodes. Chill reads elite as mini-boss (CL-7, Glacial Spikes); Guard's CL-63 reading of "normals and elites" excluded mini-bosses. Normal enemies have **1–4 HP** after the 0.75 scale.
5. **Boss-percentage precedent.** Glacial Spikes already deals Anomaly's exact numbers (mini-boss 20% max HP, boss 3%) and its comment says they're "already the boss-reduced numbers, so no further BossClass scaling" (GS 8107). Overload's 0.25/0.5s is "applied ONCE". The A5 Guard rows went the other way (Thornwall and Iron Maiden pass through `damageScale`), but those started from a normal-enemy number. `ArenaBossNode` has no `maxHealth` in the protocol (Glacial derives it as `health / healthPercent`), though every conformer already has `private(set) var maxHealth`, and the Boss Mode HP dial rescales it.

   - Dead Circuit: +0.5× duration, and only on Gravity Well card wells.
   - Riftline: +1 pierce.
7. **The Void synergies today.**
   - ×3 **Undertow**: a 30pt/s pull toward Spark within 120pt.
   - ×5 **Event Horizon**: Gravity Well card wells become 2s and 0.5 flat DPS, and gain a 40% slow that's applied only on frames where damage lands (about once per well).
   - ×7 **Singularity**: a random 90pt, 3s, 1-DPS well every 8s, even out of combat.
   - No well reaches the arena boss. Well kills are `.ground`. Wells ignore hittability, and their pull runs after the geometry resolve, so a pulled enemy can sit inside the Carrier for a frame.
8. **Range.** Phase supplies +45% of the game's projectile range; the only other source is Neutral's Long Shot (+20%). The approved Phase rework gives its pierce to Riftline and says nothing about its range.
9. **Gating.** No Void card past Phase `requires` anything, **including Erasure**, although every other tree's capstone requires its unlock. Red Smile requires both signatures; Silver Skin requires Guard only (CL-50). Capabilities come only from picked cards, so a synergy tier can't provide one.
10. **Pool and Codex.**
    - The pool has **79** cards (78 draftable plus the Panda). Void has 12 primary cards and 2 secondary (Silver Skin, Red Smile).
    - **After A6** (−Mass Tax, +Void Horror, +Shadow Edge) that's **80**, with Void at 13. This matches the spec's "stays 80". Redsmile RC5 and guard CA1 both assert 79 today.
    - Retired card definitions get deleted, with a "retired, never reuse" comment (the Static Field precedent). `sf_cards_offered` only ever grows, and the Cards codex iterates the live pool, so a retired id silently stops rendering.
    - Synergy discovery keys are `Void_3/5/7`, so renaming a tier is save-safe.
11. **"Event Horizon" is booked twice:** the ×5 synergy (UM 955) and **Erasure T5** (UM 2141, plus the build hint at GS 7299). The spec calls it Erasure T1; the meter is T1 "Unstable". The spec also renames ×3 Undertow → **Blackhole**, which the handoff didn't list. Erasure T5's copy says 75s / 105s, but arenas 1–10 run it at 0.5× (37.5s / 52.5s).
12. **One gun volley is one "primary firing event".** `updateAutoAttack` → `fireShotSpread` (GS 5438), where the DEBUG `gunVolleys` counter already sits. That path already skips kaiju and Red Smile. Per-pellet counters (Calculated Strike, Glacial condensation, Erasure Echo, Fracture, Mirror Edge) run only on modifier-bearing pellets. Glacial can absorb a whole volley's pellets, but the volley still fired.
13. **Projectiles.**
    - They're moved by hand each frame, so a speed curve is feasible.
    - The physics body is a fixed 4pt circle, so a 7× blade needs its own.
    - Pierce is a countdown with no per-enemy hit set.
    - `isPrimaryHit` = `.primary` or the icicle.
    - Shatter consumes a projectile that still has pierces.
14. **Four hit chains, not one.** The gun on an enemy, the gun on the boss, the sweep on an enemy and the sweep on the boss are four copies. A per-primary-hit rider needs all four sites, plus the Shatter early returns. The gun's boss path still lacks `apexRegisterAttack` (A7).
15. **Hostile projectiles** are one scene array (`enemyProjectiles`), moved by hand, and never collide with player shots. Absorption has precedent: the Panda sit and Vine Wall T3 both distance-scan and remove. Fired by: legacy ranged, Linekeeper bolt, Echo Leech, Faceted Lie volleys, Quench Warden, Dynamo Choir. **Area strikes** (slams, lanes, conduits, Starfall, standards) are not projectiles.
16. **Movement.**
    - `routeSteerTarget` accepts any goal, and the end-of-frame resolve slides bodies along the Carrier, so a flee can reuse both.
    - It must be a scene-side branch (like the Repulse flight), **not** through `chase`. Spurhound, Linekeeper and Ramplate read `target`/`goalPosition` as "where Spark is", and would lunge, anchor or charge at the flee point.
    - Enemies aren't wall-clamped (they spawn at R + 40), so a flee must clamp like the Repulse flight.
    - Skipping `chase` freezes scripted state machines, exactly as a stun does.
17. **States.**
    - Stun is a raw timer.
    - `OverloadStunState` is exactly Void Horror's shape: a state, then immunity after it ends.
    - The snowman is a stun in costume. **Found:** `endSnowman` zeroes `stunTimer`, which cuts short an overlapping Overload stun.
    - Freeze, slow and the Repulse flight are separate scene or node states.
    - **Bosses are not in `enemies`,** so wells, fear and pulls never see them. A new source just calls `b.takeDamage` and `onLethalHit` credits the kill. Overlap tests should use `hitBodyRadius`; mobile bosses report `targetingRadius` = 0.
18. **KillSource.** Twelve cases; `.burst` and `.sweep` are reward-only (damage harness P11a asserts exactly those). KillSource.swift:7 already anticipates a returned-projectile source. `damageEnemiesInRadius` credits `.burst`, so Anomaly, decompose and Dead Circuit kills must not route through it.
19. **Purple is used by player effects:**
    - Unstable Core's ring (0x9933CC).
    - **False Opening's tell and pulse (0x8E44FF), which is exactly `hostilePurpleHex`, the Faceted Lie's danger colour.** This is new, and stronger than Unstable Core's case.
    - Erasure T2's purple player bolts (`voidStyle`).

    The only in-world player-Void colour that isn't purple is Gravity Well's indigo (0x4466DD / 0x6688FF / 0x223366).
20. **Harness infrastructure.**
    - `extract-guard-config.sh` is Guard-specific awk; generalizing it means taking the enum name.
    - **A nested `enum Void` would shadow Swift's `Void` inside `GameConfig`**, so the enum needs another name (`VoidTree`).
    - Stubs hand-mirror `Erasure` (two constants).
    - Guard's WR12 reads only the first 6000 characters of `update()`, so A6 code inserted early there could push the Guard calls out.
    - `UpgradeManager.debugForcedCardID` exists but is **not announced** (debug-seams rule).

## D. CL-5 — runtime classification and the resulting formula (Sep 15)

Every operation in today's `applyPlayerDamage` / `PlayerStats.takeDamage`,
from source, in the order it runs:

| # | Operation (today) | Source | Exact op | Activation | Classification |
|---|---|---|---|---|---|
| 1 | Boss Mode ATK dial | `BossModeDials.atk` | `dmg *= atk` | Boss Mode only, boss-class sources only | **Input scaling** (stays first, outside the ceiling) |
| 2 | **Unyielding** (Forge Path 20B) | `GameConfig.ForgePath` | `dmg *= 0.5` | node owned AND cooldown ≤ 0 AND the RAW hit > 20% max HP; then 45s cooldown | **Percentage reduction, conditional, once per 45s → INSIDE the 90% ceiling** |

| 5 | Flat DEF | `DEF + Fortify temp + Grounded Core + Deeproot ground DEF (+ Ironhide's +10 today)` | `dmg = max(1, dmg − DEF)` | always | **Flat subtraction with a floor of 1** |

**The one exception question (design decision, not mine to make):** kaiju.
Inside the ceiling, kaiju alone still takes only 15% of every hit (0.85 <
0.90), so the transformation loses nothing on its own. It only loses when
STACKED with other reductions: today kaiju × Ironhide-90% would be 98.5%
taken-off; under the ceiling it is 90%. **RULING (Brandon, Sep 15): no exception —
kaiju goes inside the ceiling.** (Recommendation adopted as an explicit
recorded ruling, not a default.) "Pandas may violate geometry as
spectacle, not as save-state corruption" is the same instinct: the
spectacle is intact at 85%, and a 98.5% stack is where practical
immortality lives. If Brandon wants the kaiju window to stay above the
ceiling, the exact exception would be: *"kaijuDamageReduction is applied
after the ceiling, as a transformation multiplier, for its 10s window."*

**Resulting CL-5 formula (A0 builds exactly this):**

```
raw                                                  // enemy's hit
if gauntlet && bossClass: raw *= BossModeDials.atk   // 1. input scaling (unchanged)

// 2. percentage layer — multiplicative, global ceiling 0.90
forge    = min(0.60, Σ active Forge Path DR sources) // one factor, additive inside
unyield  = (owned && cd ≤ 0 && raw > 0.20·maxHP) ? 0.50 : 0   // consumes its 45s cd when it fires
ironhide = crowd-scaled 0…0.90 (rework model; replaces today's flat +10 DEF)
aegis    = 0 / 0.25 / 0.35 by tier
kaiju    = kaijuActive ? 0.85 : 0                    // RULED Sep 15: inside the ceiling, no exception
R = 1 − (1−forge)(1−unyield)(1−ironhide)(1−aegis)(1−kaiju)
R = min(R, 0.90)
dmg = raw × (1 − R)

// 3. flat DEF, floor 1
dmg = max(1, dmg − (DEF + fortifyTemp + groundedCore + deeprootGround))

// 4. barrier before health
absorbed = min(barrier, dmg); barrier −= absorbed
toHP     = dmg − absorbed
fire "hit" events (Overcharge reset, Defiant, Slipstream clock) whenever dmg > 0,
  with (absorbed, toHP) reported so reactive effects pick the right event

// 5. health + rescues — compute lethal, then rescue, THEN finalize
HP −= toHP
if HP ≤ 0:
    if braceAvailable:        HP = 1; braceAvailable = false          // first
    elif unbrokenAvailable:   HP = 1; unbrokenAvailable = false;      // second
                              invuln 10s; bonusATK = DEF for 10s
    else: death
    // a barrier-only hit has toHP == 0 and can never reach this branch
// 6. Second Breath heal (unchanged, after survival is known)
```

Explicit invulnerability (Phase Skin, i-frames) stays where it is: the
contact is ignored before step 1. Enemy boss-ATK scaling stays input
scaling. Flat DEF's floor of 1 prevents DEF alone from zeroing a hit; it
does not claim practical immortality is impossible once sustain stacks —
that is a playtest question, as the packet says.
