## What A7a added to the loop (apply to A7b)

- **Freeze discipline:** each freeze has a SHA-256 manifest of the frozen files; its digest is the first 16 hex of the manifest's own hash. Take a snapshot before every corrective, and write a corrective diff.
- **Retained mutations are coverage only when KILLED by an assertion.** A compile error or crash is INVALID, and a hang is a TIMEOUT; neither counts. Add a retained mutant for every behaviour a seam fixes.
- **The canon is generated and fingerprinted.**
  - Any seam that changes catalog data or copy must regenerate `docs/v2.1-ability-canon.md` and pass `--check`. Catalog data means descriptions, details, tiers and eligibility; the sidecar, the expectations and the generator count too.
  - A7b's close runs CL-104's final consistency refresh: the canon stops being PROVISIONAL once A7b's behaviour and copy land.
- **Copy waits for behaviour.** A copy line that describes a runtime fix ships in the same seam as the fix, never ahead of it.
- **Never stage** `WorkspaceSettings.xcsettings`, `sparkforge-card-atlas.html` or `output/` (fax PDFs, not ours).
