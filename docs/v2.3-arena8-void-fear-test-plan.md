# Void Horror — separate directional qualification recommendation

Planning only. G18 does not change Void Horror, EnemyNode.flee or FleeRule. Safe well placement is not fear-motion certification.

The current GameScene.fleeGoal and EnemyNode.flee pass the old circle radius. FleeRule.goal returns nil outside that circle; fleeStep holds there. Legal outer-room enemies therefore need both goal and step adapted. Increasing the circle or projecting a goal to nearest floor is not equivalent: a projection can pull a frightened body toward Spark.

Use the authored six-room outer bounds and full-body solid geometry, preserving existing away heading, deviation order, lookahead, speed/slow cap, chance, duration, resistance, boss immunity and all old-circle paths. A route's preferred step must pass the same separation and swept-solid checks. Hold if no legal away step exists. No crossing walls, no inward snap and no changed chase behavior when fear is absent.

| Case | Required directional evidence |
| --- | --- |
| Every legal outer room beyond the old radius | A free away direction actually moves; it is not held by the legacy radius. Sample before/after Float storage. |
| Outer wall/corner with Spark behind | Stop or slide legally; do not step inward toward Spark to satisfy a bound. |
| Doorway and corridor mouths | Full-body segment stays clear; no shortcut through a thin wall even when both endpoints are legal. |
| Preferred route heads toward Spark | Reject it; evaluate original away/deviation candidates, otherwise hold. |
| Coincident Spark/enemy | Preserve the existing fallback heading and deterministic order. |
| No legal away heading | Hold without teleporting, oscillating into solid or reacquiring a new combat target. |
| Slow, growth-scaled bodies, elite fear timing | Preserve existing effective speed/cap and class-specific clocks; no hidden range/balance change. |
| Pause, background, expiry and reset | No fear timer catch-up, stale step or movement after reset. |
| Ordinary arenas 1–7 and Boss Mode | Original circle implementation stays equivalent; normal nonfeared routing untouched. |

Model invariants: nondecreasing separation along the accepted segment (not only its endpoint), valid actual Float root, swept clearance at the live footprint, and configured step length. Independently inject old-circle hold, nearest-floor inward snap, untested-endpoint tunneling and wrong slow handling. Pair those with actual feared basic/ranged Scene actors and phone/iPad native checks. This needs its own reviewed candidate and separate ACP; no new player-facing fear rule is proposed beyond applying the existing invariant to the building.
