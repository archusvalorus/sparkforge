### CL-5 targeted runtime request

Before A0's damage-order implementation, report Unyielding's and kaiju's exact operations, values, and activation conditions from the current source. Classify each as percentage reduction, explicit invulnerability, amplification, or another operation. Percentage reductions belong inside the global 90% ceiling. Do not preserve an outside-ceiling reduction merely by calling it legacy behavior. If preserving an effect requires an exception, return that exact exception for a design decision. Enemy boss-ATK scaling remains input scaling, not player damage reduction.

Barrier-only qualifying hits still count as hits for Overcharge and relevant reactive effects (Defiant/Phase Skin). Report absorbed versus health damage so each effect can use the correct event. This does not permit barrier-only hits to consume lethal rescues. Compute the lethal outcome, use the first available rescue, then finalize survival or death; never finalize death before rescue handling.

Retain the flat-DEF floor of 1 after percentage processing and before barrier. This prevents flat DEF alone from zeroing damage. It does not prove practical immortality is impossible once healing and other sustain are considered; assess that in playtesting.

Additional approved rules:

- Percentage-based damage reductions stack multiplicatively, with a 90% combined ceiling. Brandon lowered the proposed 95% ceiling. Explicit invulnerability remains separate.
- At Ironhide's 90% alone, Aegis cannot add further percentage reduction; it still provides its other effects and supports defense at lower enemy density.
- Unbroken Core's lethal rescue creates a 10-second invulnerability/retaliation window. Gain bonus ATK equal to current DEF during that window; do not permanently replace either stat. This supersedes ambiguous `DEF = ATK` wording.
- Document flat DEF's placement in the damage pipeline. A percentage ceiling alone does not prove the player cannot become effectively invulnerable through flat DEF.

Future encounter-design consideration: defense-busting enemies that clearly telegraph their threat. This is future pressure on the playstyle, not authorization to expand this implementation into a new enemy roster.
